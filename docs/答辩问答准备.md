# 答辩问答准备

> 第三轮角色十三产出。每个问题的回答要点都**具体指向项目里的文档/参数/实测数据**，
> 不使用空洞套话；涉及数字的地方严格遵守"不虚构"原则——
> 尤其是准确率这类最容易被追问、也最容易被诱导虚报的数字。

## 一、高概率问题与回答要点

### Q1 为什么用手工特征融合，而不是端到端深度学习分类器？

回答要点（指向 `docs/技术文档.md`、`DESIGN.md` 背景）：

1. **可解释性是安全系统的硬需求**：本系统输出"为什么判你疲劳"
   （PERCLOS 多少、最长闭眼几秒、哈欠几次——报告页逐项列出），
   端到端网络给不出这种逐项归因；论文与答辩也更讲得清。
2. **资源约束**：纯浏览器、零安装、不联网。MediaPipe Face Landmarker
   （模型 3.7MB）已是浏览器端可负担的上限，再训练/部署一个端到端分类器
   超出本科毕设的工程边界。
3. **小样本现实**：端到端需要大规模标注数据，本项目只有单被试数据
   （见《局限性与威胁分析.md》§2.5），手工特征+模糊隶属函数反而更稳健。
4. 承认取舍：手工特征的天花板低于深度方法，这是"工程可落地性"与
   "方法论完整性"的权衡——本项目的贡献定位在工程实现与方法论
   （双通道融合、质量门控、离线评测工具链），不在刷准确率。

### Q2 语义否决阈值 0.40 怎么来的？单被试标定的局限怎么看？

回答要点（指向 `docs/真人实测问题汇总.md` P0/P1 条目、`docs/算法参数文献核查记录.md`）：

1. **来源**：真人实测中发现"抬头时 EAR 失真造成假闭眼"（P0 状态机锁死问题），
   引入 blendshape 语义通道做交叉验证；实测得到"真闭眼"与"姿态假阳性"
   在语义分数上的分离区间 0.427–0.613，0.40 取在分离区间下沿附近，
   留安全余量。
2. **局限如实说**：这是**单被试标定值**，文献核查未发现可直接引用的
   同类公开阈值（本项目特有的 geo/sem 双通道结构）；跨人群适用性
   必须多被试验证——已准备好《多被试测试协议.md》与知情同意书模板，
   这是后续第一步工作。
3. 兜底机制：即使 0.40 对他人偏严/偏松，系统还有个人校准（每人 8 秒
   睁眼基线）与设置面板可调参数，不是写死的黑箱。

### Q3 和商用 DMS 方案相比，这套系统的定位是什么？没做到什么？

回答要点（指向 `docs/局限性与威胁分析.md`）：

1. **定位**：零安装、纯浏览器、隐私优先（画面不离开本机）的**研究与演示
   平台**，价值在完整方法论与可复现工具链（离线评测、敏感性分析、
   消融实验、论文图表脚本），不是车规级产品。
2. **没做到的**（逐条诚实列）：
   - 车规硬件适配（红外补光、抗振动）——全部实测在静止笔记本摄像头完成；
   - 活体检测/防照片欺骗（§2.4）；
   - 遮挡鲁棒性（眼镜/墨镜/口罩，§2.1）；
   - 多人群标定与规模化准确率验证（§2.5）；
   - 肤色/光照公平性评估（§2.2，论文中必须主动声明）。

### Q4 "不上传、不落盘"怎么证明？能不能现场验证？

回答要点（指向 `tools/integration-test.mjs`、`server/server.js`）：

1. **可以现场验证**：打开浏览器开发者工具 → Network 面板 → 启动检测跑 30 秒，
   全部请求只有 `127.0.0.1` 本机回环，没有任何外部域名。
2. **自动化证据**：集成测试里有一条断言"首页无外部域名请求（离线可用）"
   （41 项集成测试之一，可现场 `node tools/integration-test.mjs` 复跑）。
3. **架构证据**：服务器是约 200 行的纯静态文件服务器，只监听 127.0.0.1，
   没有任何 POST/上传端点（代码可现场翻）；PWA 断网实测 12/12 通过
   也侧面证明系统不依赖任何网络服务。
4. 视频帧只存在于浏览器内存（video 元素 → canvas），没有任何
   `MediaRecorder`/下载/IndexedDB 持久化影像的代码路径。

### Q5 系统准确率到底是多少？

**这个问题必须诚实，绝不能编数字。** 标准回答：

1. **当前样本量不支持给出有统计意义的准确率数字。** 真人实测只有
   1 名被试、约 8 分钟有效数据，仅用于发现与修复工程缺陷（9 个问题），
   不是精度评估样本。
2. **工具已就绪，数据未到位**：视频离线评测工具（人工标注 → 混淆矩阵 →
   灵敏度/特异度/MCC）已完整实现并有合成数据链路验证
   （`tools/analysis/confusion-chart.mjs` 可一键出图），
   缺的是多被试标注数据集——《多被试测试协议.md》就是为这件事写的。
3. **能说的**：脚本动作检出率（刻意闭眼/哈欠/点头是否被系统记录）
   在单被试上表现良好（真人实测问题汇总中的修复验证数据），
   但这与"疲劳诊断准确率"是两个口径，论文中会严格区分。
4. 如果评委追问"那你的贡献是什么"：回到 Q1 第 4 点——工程实现与方法论
   （双通道融合、质量门控、可复现实验工具链、模糊测试 4000 轮零缺陷等
   鲁棒性证据），而不是精度数字。

### Q6 推理在主线程同步跑，不卡吗？为什么不用 Web Worker？

回答要点（指向 `docs/长时稳定性与性能剖析报告.md`）：

1. 实测数据：真实推理下每帧一次 50–90ms 长任务（p95=91ms），
   主线程约 2/3 时间被推理占用——**阻塞是显著的，但系统节拍本就是
   检测驱动的**，交互在帧间仍可响应。
2. 不做 Worker 化的理由（报告 §3.1 四条）：检测驱动循环并行收益有限、
   MediaPipe 在 Worker 内的兼容链未验证、无头环境测量值偏悲观、
   优先级排序（正确性 > 不破坏测试 > 可维护性 > 性能）。
3. 留了后手：`perf-profile.mjs` 可复测，未来迁移 Worker 前后直接对比数据。

### Q7 测试体系到底有多全？

| 设计 | `tools/design-audit.mjs` | Do's/Don'ts 15 项断言 |
| PWA | `tools/pwa-offline-test.mjs` | 断网实测 12 项 |

### Q8 UI 为什么长这样？"像苹果"有没有客观标准？

回答要点（指向 `DESIGN.md`、`docs/Apple设计保真度审计报告.md`）：

1. DESIGN.md 是对 apple.com 真实页面逐 token 提取的规范（字号/字重/字距/
   间距/圆角/阴影/动效曲线），不是"感觉像"。
2. 保真度用**脚本核对**而非口头宣称：design-audit 读 computed style
   逐条断言（正文 17px/400/-0.374px、全站无 font-weight:500、
   卡片零阴影、圆角只用令牌阶梯、scale(0.95) 按下反馈等 15 项全过）。
3. 与无障碍的冲突有裁决记录：安全信息优先 WCAG AA（UI设计说明末两节）。

## 二、5 分钟演示脚本（用演示模式，不需要真的睡着）

> 前置：`一键启动.bat` 已启动；浏览器全屏；提前 `/?pwa=0` 确保开发模式。
> 演示模式走的是合成剧本（清醒→轻度→中度→重度循环），完整展示四级预警。

| 时间 | 动作 | 讲解词要点 |
|---|---|---|
| 0:00–0:30 | 停在首页，滚动一屏 | "零安装、纯浏览器、画面不离开本机——开发者工具 Network 面板可以现场看，只有本机回环请求" |
| 0:30–0:50 | 点"开始检测"→ 演示模式（设置抽屉里打开"演示模式"再开始，或直接按测试钩子） | "没有摄像头也能走通全流程——合成驾驶员剧本" |
| 0:50–1:30 | 工作台观察：疲劳指数曲线爬升，等级芯片 清醒→轻度 | "五个特征实时计算：PERCLOS、眨眼时长、哈欠、点头、头部偏离；融合权重在右侧可见" |
| 1:30–2:00 | 轻度报警横幅出现（横幅+闪屏） | "四级预警第一级；报警有文字+图标双通道，不只靠颜色" |
| 2:00–2:40 | 切专业模式（顶栏"专业模式"按钮）：展示 EAR/MAR 波形、融合贡献明细 | "可解释性：每一分加在哪、为什么加，全部看得见" |
| 2:40–3:20 | 中度→重度：报警升级、分数到 90+ | "危险闭眼 1.8 秒触发最高级报警，绕过平滑直接置顶——安全优先设计" |
| 3:20–3:50 | 点"结束检测"→ 报告页 | "报告含结论、状态分布、行为统计、全程曲线、建议——可直接导出 CSV 供论文分析" |
| 3:50–4:30 | 专业模式报告页：点"运行敏感性分析"，展示稳定平台区图 | "参数不是拍的：敏感性分析显示默认值落在不敏感的稳定平台区" |
| 4:30–5:00 | 收束 | "三层质量保障：125 项回归 + 41 项集成 + 4000 轮模糊测试；准确率口径如实：单被试标定，多被试协议已就绪" |

**应急预案**：
- 浏览器卡顿 → 刷新后重新进演示模式（无状态依赖）；
- 评委要求真摄像头 → 说明需授权，切 `/?pwa=0` 后正常开始检测即可
  （假摄像头 e2e 测试已验证真实推理链路 GPU 44ms/帧）；
- 被问住 → 引到对应文档（每份文档都写了"未验证项"，诚实是本项目的设计原则）。
