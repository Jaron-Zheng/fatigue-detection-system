# 答辩问答准备

> 每个问题的回答要点具体指向项目里的文档/参数/实测数据，不使用空洞套话。

## 一、高概率问题与回答要点

### Q1 为什么用手工特征融合，而不是端到端深度学习分类器？

1. **可解释性是安全系统的硬需求**：系统输出"为什么判你疲劳"（PERCLOS 多少、最长闭眼几秒、哈欠几次——报告页逐项列出），端到端网络给不出逐项归因。
2. **资源约束**：纯浏览器、零安装、不联网。MediaPipe Face Landmarker（模型 3.7MB）已是浏览器端可负担的上限。
3. **小样本现实**：端到端需要大规模标注数据，本项目只有单被试数据，手工特征+模糊隶属函数反而更稳健。
4. 承认取舍：手工特征的天花板低于深度方法，这是"工程可落地性"与"方法论完整性"的权衡。

### Q2 语义否决阈值 0.40 怎么来的？单被试标定的局限怎么看？

1. **来源**：真人实测中发现"抬头时 EAR 失真造成假闭眼"，引入 blendshape 语义通道做交叉验证；实测得到"真闭眼"期间语义闭合度 0.61–0.74 与"姿态假阳性"期间 0.08–0.43 的分离区间，0.40 取在两者分界点附近。
2. **局限如实说**：这是单被试标定值，跨人群适用性必须多被试验证——《多被试测试协议.md》已就绪。
3. 兜底机制：个人校准（每人 5 秒睁眼基线）与设置面板可调参数。

### Q3 和商用 DMS 方案相比，这套系统的定位是什么？

1. **定位**：零安装、纯浏览器、隐私优先（画面不离开本机）的研究与演示平台。
2. **没做到的**：车规硬件适配、活体检测、遮挡鲁棒性（眼镜/墨镜/口罩）、多人群标定、肤色/光照公平性评估。

### Q4 "不上传、不落盘"怎么证明？

1. **现场验证**：开发者工具 Network 面板 → 启动检测跑 30 秒，全部请求只有 `127.0.0.1`。
2. **自动化证据**：集成测试有一条断言"首页无外部域名请求"（41 项集成测试之一，可现场 `node tools/integration-test.mjs` 复跑）。
3. **架构证据**：服务器是零依赖静态文件服务器，只监听 127.0.0.1，没有 POST/上传端点；PWA 断网实测 12/12 通过。

### Q5 系统准确率到底是多少？

1. **当前样本量不支持给出有统计意义的准确率数字。** 真人实测只有 1 名被试、约 8 分钟有效数据。
2. **工具已就绪，数据未到位**：视频离线评测工具（人工标注 → 混淆矩阵 → 灵敏度/特异度/MCC）已完整实现。
3. **能说的**：脚本动作检出率在单被试上表现良好，但这与"疲劳诊断准确率"是两个口径。
4. 贡献定位在工程实现与方法论（双通道融合、质量门控、可复现实验工具链、模糊测试 4000 轮零缺陷）。

### Q6 推理在主线程同步跑，不卡吗？

1. 实测：每帧一次 50–90ms 长任务（p95=91ms），主线程约 2/3 时间被推理占用——阻塞显著，但系统节拍本就是检测驱动的，交互在帧间仍可响应。
2. 不做 Worker 化的理由：检测驱动循环并行收益有限、MediaPipe 在 Worker 内的兼容链未验证、优先级排序（正确性 > 不破坏测试 > 可维护性 > 性能）。

### Q7 测试体系到底有多全？

| 层 | 工具 | 规模 |
|---|---|---|
| 静态 | `node tools/project-check.mjs` | 6 项类别（101 个 JS 文件语法 + 254 个 id + 安全基线 + 设计令牌一致性 + SW 预缓存） |
| 单元/回归 | `node tools/regression-test.mjs` | 205 项 |
| 集成/安全 | `node tools/integration-test.mjs` | 41 项 |
| 端到端（真推理） | `tools/e2e-fake-camera-test.mjs` | 假摄像头 GPU/CPU 各 11 项 |
| 无障碍 | `tools/a11y-test.mjs` | 10 场景 critical/serious 清零 |
| 模糊 | `tools/fuzz-test.mjs` | 4000 轮 263 万帧零产品缺陷 |
| PWA | `tools/pwa-offline-test.mjs` | 断网实测 12 项 |

### Q8 UI 设计语言是什么？

1. 项目使用 Apple 设计语言：Action Blue `#0071e3`、五级双光源阴影体系（xs~xl）+ 辅助阴影、负字距 tight headline、弹簧缓动曲线、胶囊圆角 CTA。
2. `tokens.css` 头部注释记录了令牌清单，设计令牌一致性检查（`project-check.mjs` 第 6 项）确保 4 个样式文件无字面量颜色。
3. 与无障碍的冲突有裁决记录：安全信息优先 WCAG AA ≥4.5:1。
