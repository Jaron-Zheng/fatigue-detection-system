## 一、项目概述

### 技术栈

- 运行环境：Node.js ≥ 18（仅本地静态服务器与测试工具链使用）
- 前端：原生 ES Modules JavaScript，**零运行时依赖**
- 视觉引擎：MediaPipe Face Landmarker（TFLite WASM，`web/vendor/` 内自包含，支持离线运行）
- 测试：playwright-core（仅 devDependency）+ Node 内置能力
- 入口：`server/server.js`（本地静态服务器，默认 5180 端口）→ `web/index.html`

### 功能清单

1. **实时疲劳检测**：七特征融合（PERCLOS、眨眼频率、眨眼时长、最长闭眼、哈欠、点头、视线偏离）→ 四级预警（正常 / 轻度 / 中度 / 重度）
2. **个人校准**（睁眼 EAR 基线等）
3. **演示模式**（无摄像头仿真数据，开箱即演示）
4. **专业模式**：敏感性分析、消融实验、视频文件评测、专家参数面板
5. **会话记录与导出**：HTML 报告、JSON、CSV 三种格式
6. **设置持久化**（localStorage），多标签页同步
7. **PWA 离线**（Service Worker 预缓存）
8. **深浅色主题、静音、键盘可达性**

## 二、第一轮：应用层修复

### 1. Service Worker 预缓存清单与源文件不同步

- **文件**：`web/sw.js`
- **现象**：静态检查报告「预缓存清单过期」，PWA 离线缓存可能向用户提供旧版本资源
- **根因**：源文件迭代后未重新生成预缓存指纹清单
- **方案**：运行 `tools/gen-sw-precache.mjs` 重新生成，project-check 恢复全绿

### 2. 中文界面拉丁单位与项目文案约定不一致

项目自身约定「中文界面使用毫秒 / 秒」，但多处展示文案使用了拉丁缩写 ms / s，共 9 处，涉及 `report.js`、`settings.js`、`index.html`、`fusion.js`、`evaluation-ui.js` 等文件。仅展示文案修改，判定逻辑、阈值数值、单位换算零改动。

## 三、第二轮：深度优化

以"分角色全面审计"方式对首轮优化后的代码做二次深挖：审计全部 46 个前端源文件与核心工具链，确认并修复 4 项问题，新增 10 条回归断言，全量测试 205/205 通过。

### 修复明细

1. **帧率下限一致性**：`capture.targetFps` 的配置 schema 允许最小值 1，而渲染循环与帧呈现器内部硬钳到 8。现统一收口为 `config.js` 导出的 `MIN_CAPTURE_FPS = 8`。
2. **PERCLOS 隶属边界单源真相**：论文参数 0.06 / 0.32 此前在 `fusion.js`、`analysis.js`、`accuracy-eval.mjs` 各自硬编码，存在"改一处漏一处"风险。现收口为 `config.js` 导出的 `PERCLOS_MU_LO / PERCLOS_MU_HI`，5 处调用点全部改引用。
3. **评测 seek 兜底**：`video-source.js` 逐帧评测在"当前已是目标位置"分支仅依赖 requestAnimationFrame，后台标签页 rAF 可能永不触发导致评测挂起；已补 200ms setTimeout 超时兜底。
4. **报警器极端路径防御**：AudioContext 创建成功但 GainNode 创建失败的部分初始化极端场景下，`masterGain` 为 null 仍可能被触发；`beep()` 已增加空值守卫。

## 六、运行与使用说明

```bash
# 启动（应用零运行时依赖，无需 npm install 即可运行）
node server/server.js
# 浏览器访问 http://127.0.0.1:5180/

# 可选：安装测试工具链依赖（仅运行浏览器测试需要）
npm install

# 常用验证命令
node tools/project-check.mjs       # 静态检查
node tools/regression-test.mjs     # 回归测试
node tools/integration-test.mjs    # 集成测试（需先启动服务器）
```

- 无摄像头环境可点「演示模式」直接体验完整检测流程
- 完整使用手册与常见问题见 `README.md` 与 `docs/` 目录
