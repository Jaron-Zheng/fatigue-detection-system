# 论文图表使用说明

> 第三轮角色十产出。`tools/analysis/` 下的脚本把系统导出的 CSV 数据
> 直接变成论文可用的矢量图（SVG）。本文说明**每张图对应论文哪一节、
> 如何重新生成、数据换成多被试真实数据后脚本无需改动即可复用**。
>
> **技术选型降级说明**：任务书建议 Python + matplotlib，但本环境没有
> 可用的 Python 解释器（仅有 Microsoft Store 占位程序），按任务书的
> 降级方案改用 Node.js 直出 SVG。SVG 本身是矢量格式，满足论文
> "≥150dpi 或矢量"的要求，且零依赖（不需要任何 npm install）。

## 一、图表清单与论文位置

| 脚本 | 输入 | 输出 | 对应论文章节 |
|---|---|---|---|
| `confusion-chart.mjs` | 视频评测指标汇总 CSV | `混淆矩阵.svg` | 实验结果 · 系统检出效果 |
| `sensitivity-chart.mjs` | 参数敏感性分析 CSV | `敏感性_<参数名>.svg` ×5 | 参数选取依据 · 稳定平台区论证 |
| `ablation-chart.mjs` | 权重消融实验 CSV | `权重消融贡献度.svg` | 消融实验 · 各特征贡献度 |
| `session-chart.mjs` | 会话指标 CSV（+同名 JSON） | `会话疲劳指数时序.svg` | 系统运行实例 · 全程曲线 |

默认输出目录：`docs-evidence/figures/`（SVG 原图 + PNG 预览）。

## 二、运行方式

```powershell
# 0. 没有真实数据前，先用真实管线生成的合成示例数据打通链路：
node tools/analysis/gen-fixtures.mjs

# 1. 混淆矩阵（输入=报告页"视频评测"→"导出指标汇总 CSV"）
node tools/analysis/confusion-chart.mjs <指标汇总.csv> [输出.svg]

# 2. 参数敏感性（输入=报告页专业模式"运行敏感性分析"→"导出分析结果 CSV"；
#    多个参数的导出可合并成一个文件，脚本按"参数名"列自动分组）
node tools/analysis/sensitivity-chart.mjs <敏感性.csv> [输出目录]

# 3. 权重消融（输入=报告页专业模式"运行权重消融实验"→"导出分析结果 CSV"）
node tools/analysis/ablation-chart.mjs <消融.csv> [输出.svg]

# 4. 会话时序（输入=报告页"导出 CSV"；同目录若有同名 .json 会自动读取，
#    用于标注报警触发点）
node tools/analysis/session-chart.mjs <会话.csv> [会话.json] [输出.svg]
```

所有脚本对参数缺省友好：不带参数时用 `fixtures/` 里的示例数据运行，
方便评审者一键复现。

## 三、换成多被试真实数据的工作流

1. 按《多被试测试协议.md》完成采集，得到每位被试的会话 CSV/JSON；
2. 视频评测：给每位被试的视频做人工标注 → 导出"指标汇总 CSV"，
   逐份喂给 `confusion-chart.mjs`（输出文件名加被试编号）；
   跨被试汇总时把多份 CSV 的 TP/TN/FP/FN 相加后再跑一次，即得总体混淆矩阵；
3. 敏感性/消融：在每位被试的会话上跑报告页内置工具并导出，
   合并同参数行后喂给对应脚本——**脚本不需要任何修改**，
   因为它们只认界面导出的表头格式；
4. 论文插图用 SVG 原件；需要位图的场合用浏览器打开 SVG 截图，
   或 `tools/shot-svg.mjs <图名…>` 批量转 PNG。

## 四、示例数据的重要声明（务必写进论文脚注）

`fixtures/` 里的数据由 `gen-fixtures.mjs` 用**演示模式合成剧本**经过
与产品完全相同的管线（指标层→融合层→报警→记录层）生成，其中"人工标注"
是剧本阶段名的机械映射（清醒→正常、其余→疲劳）。因此：

- 混淆矩阵示例中灵敏度偏低（约 64%）是**系统平滑/滞回机制在阶段切换沿口的
  固有延迟**造成的合成现象，不代表真实检出能力；
- **论文中出现的任何数字必须来自多被试真实数据**，示例数据只用于
  验证脚本与图表管线可用。
