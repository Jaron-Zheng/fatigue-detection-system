# 第六轮：开关状态一致性混沌（2026-08-17）

用户报告：专业模式下下载的 HTML 报告有时仍和普通模式一样。以「打开→关闭→
打开，功能必须仍然是打开的；导出文件必须与开关状态一致」为核心思想，
新增 `tools/toggle-chaos-test.mjs` 定向混沌。

## 定位与修复

**根因**（export-report.js 空壳折叠逻辑）：折叠不区分模式——

- 普通模式导出：未运行的三张专业分析卡被折成可见的「本次会话未运行」
  文案 → 专业术语泄漏进普通用户报告；
- 专业模式导出：分析卡没跑时折成同一行文案 → 与普通版肉眼无异
  （用户报告的「两份一样」实锤）。

**修复**：按模式分流。普通模式从导出克隆整体剥离全部 `.pro-only`
元素（页上看不到的，报告里就不该有）；专业模式保持空壳折叠。
修复后普通版 95.6KB / 专业版 97.8KB，参数表与专业卡仅专业版可见。
