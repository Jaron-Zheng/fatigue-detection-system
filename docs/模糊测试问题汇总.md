## 一、测试设计与覆盖面

**随机化剧本生成器**（`FuzzDriver`，接口与 `sim-driver.js` 的 `frame()` 输出形状一致）：

| 维度 | 随机化方式 |
|---|---|
| 闭眼时长 | 40% 压在 **50–150ms 边界带**（正常眨眼窗口 60–500ms，边界最易出 bug）；30% 正常眨眼 150–500ms；20% 长闭眼 0.5–1.5s；10% 微睡眠级 1.5–4s |
| 闭眼间隔 | 300–5500ms 均匀摇动 |
| 头部姿态 | 摆幅 1–19°、35% 概率附加 5–20° 持续低头、点头尖峰幅度 10–50°（远超判定阈值）、0.2% 概率 ±60–90° 姿态突变 |
| 人脸丢失 | 0.08%/帧概率触发 0.5–8s 的 `ok:false` 丢失段 |
| 帧率抖动 | 16–120ms 随机帧间隔；2% 概率 500–2000ms 大卡顿；0.5% 概率重复时间戳（dt=0） |
| 极端特征值 | 0.4% 概率 EAR 打到 0 或 0.45–0.55（含轻微负值噪声）；0.3% 概率 MAR 打到 0.9–1.2 |
| 视线偏离 | gaze 每帧 ±20°/±15° 随机 |

**状态机模糊**：向 `SessionStateMachine` 注入 300 步随机事件序列（12 种事件 × 4 种载荷含空载荷/无校准/有校准），每步断言 `can()` 与 `send()` 行为一致、状态始终合法、被拒绝时状态不变；序列结束后断言**存在合法出路**（不死锁）。

**每轮管线断言**（逐帧）：

- `fusion.score` 有限且 ∈ [0, 100]
- `fusion.level` ∈ {awake, mild, moderate, severe}
- 指标层 9 个数值字段有限（比例类字段额外断言 ∈ [0,1]）
- `indicators.events` / `recorder.events` ≤ `CONFIG.record.maxEvents`(2000)
- `recorder.samples` ≤ `maxSamples`(7200) + 64 条批量驱逐容忍量
- 收尾 `recorder.summary()` 不抛异常、`durationMs` 有限非负

## 三、测试过程中撞出的两个边界问题（均为测试侧/语义澄清，非产品缺陷）

### F-1 `avgBlinkMs` 在首次眨眼前为 NaN —— 既有语义，断言已尊重

- **现象**：模糊测试首帧即报 `指标 avgBlinkMs 非法: NaN`。
- **根因**：`EventWindow.meanPayload()` 在窗口内无事件时按约定返回 `NaN`（"无数据"），
  与 `null` 同义。下游三处均已守卫：`fusion.js` 第 103 行 `Number.isFinite` 判空后置 0、
  `recorder.js` 第 120 行落盘为 `null`、`fusion.js` 第 349 行 UI 文案显示 `--`。
- **处理**：不改产品代码（该语义全链路一致，改 0 反而会被误读成"眨眼时长为 0"）。
  模糊测试断言对该字段放行 NaN，并在脚本内注释说明约定。
- **验证**：放行后 4000 轮复跑，该断言不再触发，其余断言照常生效。

### F-2 状态机"死锁探路"断言自身的假阳性 —— 测试代码缺陷，已修复

- **现象**：种子 7946/7951/7961/8044/8060 报 `随机序列后状态机不可恢复: state=running/paused`。
- **复现条件**：随机序列恰好停在 RUNNING/PAUSED 时必现。
- **根因**：测试的探路逻辑固定发 `START→CANCEL`，但 RUNNING 状态下 `START` 是**非法迁移**
  （迁移表只允许 PAUSE/FINISH/RECALIBRATE/SIM_ENTER/SIM_EXIT/FAIL）——
  被拒是状态机的**正确行为**，是断言写错了，不是状态机死锁。
- **修复**：改为枚举全部合法出路（`SIM_EXIT` 直达 IDLE、`FINISH→REPORT→START→CANCEL`、
  `RESUME→FINISH→…`、`CANCEL`、`START→CANCEL`），任一可达 IDLE 即非死锁。
- **验证**：修复后两个种子各 200 组序列全部通过；该修复不触碰任何产品代码。

## 四、结论

在当前融合算法与状态机实现下，**4000 轮随机剧本（含大量 50–150ms 边界闭眼样本、
人脸丢失、帧率抖动、重复时间戳、极端特征值）与 400 组随机状态迁移序列未发现新缺陷**。
该结果可作为论文"系统鲁棒性"一节的可引用证据（注明种子与轮次即可复现）。

**未覆盖的范围（如实声明）**：模糊输入仅限指标层以上的合成特征（与演示模式同一入口），
不涉及 MediaPipe 关键点提取本身（那一层需要真实视频，见角色四的假摄像头 e2e）；
未注入 NaN/Infinity 作为输入——真实链路中 MediaPipe 不产出此类值，注入属于测试
"不存在的场景"。
