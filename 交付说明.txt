----------------------------------------------------------------

4. docs-evidence/                 实验证据包：实验报告.md、准确率评估报告.md、

7. README.md                      项目总览、快速开始、隐私架构、测试说明

二、运行方法（详见 README「快速开始」）
----------------------------------------------------------------
环境要求：Node.js 18+（仅需安装 Node，无需 npm install）、
          Chrome / Edge 浏览器、摄像头

1. 解压本交付包到任意目录
2. 双击「一键启动.bat」
   （或命令行执行：npm start）
3. 浏览器自动打开 http://127.0.0.1:5180
4. 点击「开始检测」，授权摄像头，完成 5 秒个人校准后进入实时检测

无摄像头时验证功能：访问 http://127.0.0.1:5180/?demo=1
（演示模式，按生理演进剧本合成清醒→轻度→中度→重度完整过程，
 四级分级报警依次触发，每次报警附 Top3 贡献特征归因）

三、验收自检（六项，打包前已全部通过）
----------------------------------------------------------------
1. 系统能启动    双击 一键启动.bat，服务起在 127.0.0.1:5180
2. 检测正常      演示模式跑完一个剧本，四级报警依次触发，归因面板显示 Top3
3. 报告可导出    报告页导出指标 CSV（UTF-8 BOM，Excel 可直接打开）与 JSON
4. 实验可复现    node tools/accuracy-eval.mjs 等命令一键重生成全部图表
                （命令清单见 docs-evidence/实验报告.md 末尾「复现清单」）
5. 质量门禁      npm run verify:full = 静态检查 6 + 回归测试 138 +
                集成/安全测试 41 + typecheck/lint 0 errors
6. 断网可用      node tools/pwa-offline-test.mjs（12/12 通过为基线）

四、核心指标（与 docs-evidence/实验报告.md 强绑定，均有复现命令）
----------------------------------------------------------------
- 判别力：AUC = 0.99987，AP = 0.99996（43,650 采样点）
- 工作点：灵敏度 86.4% / 特异度 100% / F1 0.927 / MCC 0.702
- 检出延迟：均值 15.3s（10 个疲劳区间检出 10 漏检 0）；
  危险闭眼由 override 通道保证秒级响应（≥1.8s 直接判重度）
- 鲁棒性：六类对抗场景零误报（4 场景 450/450 帧清醒，2 场景如实报告
  信号不可用）
- 稳定性：60 分钟无人值守无内存泄漏（JS 堆 2.98–10.11MB GC 锯齿）

注意：以上评估数据为 SimulatedDriver 合成剧本口径（标签由剧本相位
定义），论文与答辩陈述时须如实说明；接入真实标注视频可用同一命令
重跑评测（工具链已就绪）。

五、隐私承诺
----------------------------------------------------------------
摄像头画面全程只在浏览器内存中处理，不上传、不落盘、不录音；
本地服务器仅提供静态文件服务（无 POST 端点）；关闭网页后不留下
任何影像数据。集成测试含三条安全断言兜底：首页无外部域名请求、
CSP 头正确、服务器无上传端点。
