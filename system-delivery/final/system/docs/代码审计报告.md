## 审查过但未发现需要修改的部分

以下模块经过逐行审读，确认现状合理、不做无谓改动（符合「避免过度封装」原则）：

- **web/js/core/fusion.js**：EMA 平滑、override 安全兜底（含 EMA 内部状态同步抬升）、
  滞回 + 驻留 + 逐级降级 + 最短保持四重防抖、unreliable 期间停止统计累计——
  均正确且有实测依据注释。
- **web/js/core/indicators.js**：人脸丢失时冻结眼睛状态机 + PERCLOS 时间累积中断、
  事件上报去抖而内部状态不去抖、微睡眠不重复计入眨眼窗口、
  语义否决单向性（只提前结束闭眼、不阻止进入）——均正确。
- **web/js/core/calibration.js / quality.js / features.js**：个体基线校准、
  取景与光照门控、EAR/MAR/欧拉角计算，与 docs/技术文档.md 描述一致。
- **web/js/core/recorder.js / csv-schema.js**：CSV 公式注入防护（csvCell）
  已有且被回归测试 [1] 覆盖；UTF-8 BOM + 中文表头往返一致性被测试 [4] 覆盖。
- **内存与生命周期**：环形缓冲/时间窗口有容量与窗口双上限；事件数组有
  maxEvents 上限；图表每帧复用 canvas；模型在 FaceEngine 内单例管理。
  未发现未清理定时器 / 未取消 rAF / 未释放流的代码路径。
