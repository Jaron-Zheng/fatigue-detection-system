# UI 设计说明

## 设计目标

以 Apple 官网（apple.com / Apple Store 页）与 macOS / iOS 系统界面为基准，
把「毕业设计后台」重做为「有完整产品感的消费级应用」。
三条硬规则（源自 DESIGN.md 对 apple.com 的实测分析，全站不得违反）：

1. **只有一个强调色**：按钮 `#0071e3`、正文链接 `#0066cc`（深色下 `#2997ff`）；
2. **不用任何装饰性渐变**；
3. **阴影只给浮层**（弹窗/吐司/警报），卡片一律靠描边与底色分层。

所有取值不是凭感觉定的：`tokens.css` 头部注释记录了来自 apple.com
computed style 的实测基准（44px 顶栏、17px 正文、980px 胶囊按钮、
`cubic-bezier(0.4,0,0.6,1)` 统一缓动、按下 `scale(0.95)` 等）。

## 页面结构

### 首屏（viewHome）—— Apple 营销页骨架

- 一屏一块全幅磁贴（tile），浅底 / 近黑底交替产生节奏，分隔靠底色本身；
- 磁贴 1（浅底）：隐私 eyebrow + 超大标题（hero clamp 40~56px）+
  单句主张 + 开始检测 CTA + 原创 SVG「本地视觉引擎」产品示意图；
- 磁贴 2（近黑）：四项能力卡，讲技术用深色底提信息密度；
- 磁贴 3（羊皮纸浅灰）：关键数字收尾（478 关键点 / 7 类特征 / 4 级预警 / 0 字节上传），
  数字从 0 滚动入场（count-up）。

### 工作台（viewWork）—— 专业工具布局

- 左侧：大圆角视频画面（真实宽高比、镜像可选）+ 覆盖层开关（识别点/镜像/实时数值）
  以文字按钮移出画面，避免遮挡面部；趋势图与专业模式波形图在下；
- 右侧：疲劳指数环形仪表 + 等级徽章 + 六指标卡（普通模式）→
  专业模式追加眨眼频率/时长、融合贡献明细、个人基准值；
- 校准环、待机/错误/暂停遮罩覆盖在画面上，带恢复操作按钮。

### 报告页（viewReport）

- 摘要 pill 条 + 概要/状态分布/行为统计三卡 + 全程曲线 + 建议列表；
- 专业模式追加：参数敏感性分析、权重消融、离线复现、视频离线评测、参数环境表。

### 双层导航（Apple Store 结构）

- 第一层 44px 全局条：品牌 + 视图入口；第二层 52px 毛玻璃产品条：
  当前产品名、运行状态、专业模式开关、设置；滚动后第二层才浮现毛玻璃。

## 设计系统（tokens.css）

| 维度 | 规则 |
|---|---|
| 色板 | ink/canvas/parchment 三层骨架色 + iOS 系统语义色（ok/warn/caution/danger）；疲劳四级独立命名供图表复用 |
| 字阶 | display（营销）与 text（界面）两套；正文 17px；字阶刻意无 500 字重 |
| 圆角 | 0 / 5 / 8 / 11 / 18 / 20 / 28 / 980px（胶囊）阶梯 |
| 阴影 | xs/sm/md 置 none（规则强制），lg/xl 仅服务浮层 |
| 间距 | 8pt 网格 + 17px 文字内边距 + 80px 分区间呼吸 |
| 动效 | `--ease-apple` 全站状态变化统一；进场「下推淡入」24px、1s、末段极缓；错峰 90ms |

JS 通过变量名读取的令牌（`--accent`、`--lv-*`、`--chart-*`、`--mesh-*` 等）
在 tokens.css 头部注释中列有清单，改名会破坏图表与叠加层配色。

## 深色模式

- `@media (prefers-color-scheme: dark)` 跟随系统 + `[data-theme]` 手动覆盖，
  两份副本有意重复（一份不可覆盖另一份的优先级问题）；
- 不是简单反转：磁贴底色换成两级近黑保留节奏、链接换 `#2997ff`、
  语义色换 iOS 深色系统色（纯黑底上不发灰）、阴影加深。

## 动画与性能

- 全部动画走 transform / opacity，避免重排；
- `prefers-reduced-motion` 时降级为纯淡入；悬停交互仅在
  `hover:hover` + `pointer:fine` 设备启用（触屏无伪悬停）；
- 进场动效由 IntersectionObserver 触发一次即止，不持续占用主线程。

## 响应式

- 1920 / 1440 / 1366 / 平板 / 390px 移动端均有实测截图
  （`system-delivery/comparison/after/`）；
- 移动端可浏览首页、查看报告与基础操作；实时检测建议桌面进行。

## 无障碍

- 语义化标签 + 标题层级 + skip-link；
- 弹窗 role=dialog + aria-modal + Escape 关闭 + Tab 焦点陷阱；
- 状态不只依赖颜色（文字 + 图标 + 徽章）；图表 canvas 带 aria-label；
- 指标卡的 `?` 提示带 title 全文解释。
