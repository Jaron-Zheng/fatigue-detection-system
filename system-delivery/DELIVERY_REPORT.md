## 5. 未验证项（如实列出）

1. 真实摄像头授权、模型加载耗时、WebGL 实时帧率——需物理设备；
2. Firefox / Safari——当前环境仅 Chromium；
3. 声音报警与语音播报实际声响——需有声设备；
4. 长会话（>30min）内存曲线——需真人长时采集；
5. Windows 10 与双击 .bat 图形流程——本机 Win11，链路已命令行实测；
6. 文件拦截（A-07/08/09）的浏览器端实际弹窗——需人工选择真实超大文件复核；
7. Node 低版本（<18）启动分支——本机仅 v24，无法复现。
